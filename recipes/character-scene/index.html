The garden band.

Five friends, one song. Each one arrives on their own beat, then keeps breathing while the page waits.

The entrance

One cast, five beats

Every character starts 46 px low, scaled to 0.55 and tilted −8°, then springs in. The delay is index × 85 ms + 420 ms — the headline gets the first beat, the cast takes the rest.

  • Same keyframe, different --i
  • cubic-bezier(.34,1.56,.64,1) gives the overshoot
  • Never two arrivals on the same frame
The idle

Keep it alive, quietly

Each character bobs on its own 4.2 s loop with a negative delay, so they never sync. Eyes blink on a 5.4 s cycle. Both are pure transform and both stop offscreen.

  • Ambient loops: 3–6 s, ease-in-out
  • Negative delay = instant variety
  • Hover pokes: squash, stretch, settle
The words

Type it on, don't fade it

The headline is written character by character with a block caret. It reads as someone arriving, not a slide appearing — and it gives the cast something to react to.

  • 45 ms per character, monospace caret
  • Subtitle waits for the last glyph
  • Reduced motion prints the full line
