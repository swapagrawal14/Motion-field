Every label resolves.

Use it for

Short labels with attitude

Nav items, eyebrows, tags, buttons and hero labels. Best in monospace, where every glyph has the same width and the line never jiggles.

Knobs

Tune the noise

  • 620ms default duration (420 on hover)
  • GLYPHS character set — keep it to 16–20 marks
  • solved = floor(p * length) left-to-right reveal
  • spaces are never scrambled
Reduced motion & perf

Instant, no jitter

With reduced motion the function returns before touching the text, so the real label is always shown. Each element keeps its own rAF id and cancels the previous run, so hovering fast never stacks loops.
