Recipe 05 · Scroll-linked & entrances

Draw the line with the scroll.

A single SVG path traces a journey between steps, and retraces when you scroll back. The stroke is scrubbed by scroll progress, the nodes light up as the line reaches them.

Use it for

Journeys and processes

Timelines, how-it-works rails, onboarding steps, a story with a direction. The line gives the eye a path to follow between blocks that would otherwise be four disconnected cards.

Knobs

Tune the draw

  • pathLength="1" → dash math stays 0–1
  • 0.9 / 0.55 in target() sets when it starts and how far it travels
  • cut[] node thresholds (0.02, 0.34, 0.66, 0.99)
  • stroke-dasharray: 2 10 for the ghost line
Reduced motion & perf

One frame, no work

With reduced motion the line is drawn completely and every step is lit. Only stroke-dashoffset changes per frame — no layout reads inside the loop except one rect per scroll event.
