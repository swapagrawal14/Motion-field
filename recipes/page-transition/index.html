Recipe 18 · Big moments

Leave one page, arrive in the next.

A wipe covers the old page and reveals the new one, with a curtain fallback for browsers without the View Transitions API. Reduced motion swaps instantly. This demo runs both pages inside one document.

Use it for

Multi-page sites

Case studies, documentation, portfolios — anywhere a click should feel like moving through one space rather than loading a new file. Keep it under 450 ms.

Knobs

Tune the wipe

  • .42s curtain duration (190 ms to the swap)
  • transform-origin bottom → top for the cross
  • ::view-transition-old/new durations
  • gradient stops set the curtain colour
Reduced motion & perf

Instant, no curtain

Reduced motion swaps immediately and hides the curtain. The View Transition API does the heavy lifting in supporting browsers; the fallback is one composited transform animation.
