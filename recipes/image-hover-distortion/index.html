Recipe 16 · Big moments

Images that ripple under the pointer.

On hover the image warps through an animated displacement map — the grain shifts, the edges breathe, then it settles. SVG filters keep it tiny; swap in a WebGL pass when you need it on a full grid.

weight · small deps · SVG filter (or WebGL) trigger · hover GPU filter
Use it for

Work that should feel alive

Portfolio covers, editorial cards, product photography. The warp is a texture, not a gimmick: keep it subtle (scale 20–30) and let it settle when the pointer leaves.

Knobs

Tune the ripple

  • scale 0 → 26 displacement strength
  • baseFrequency 0.012 0.02 grain size
  • numOctaves 2 detail (1 = smoother)
  • 0.12 lerp in/out
Reduced motion & perf

No filter, no cost

With reduced motion the filter is removed entirely. The animation only runs while a figure is hovered or focused, and stops when it settles back to 0.
